# AI Agent: API vs SDK

השוואה בין סוכן חנות שנכתב ידנית מול OpenAI API (`agent_api.py`) לבין אותו סוכן עם OpenAI Agents SDK (`agent_sdk.py`).

```powershell
pip install -r requirements.txt
copy .env.example .env      # ממלאים את OPENAI_API_KEY
streamlit run app.py        # או: python agent_api.py / python agent_sdk.py
```
